# 🎮 Simple Python Game

A simple and fun game built as my **first Python project** after learning the fundamentals of the language.

This project was created to practice basic Python concepts and understand how different modules and data structures can be combined to create an interactive program.

---

## 📌 About the Project

This was my first attempt at building something using Python rather than simply writing individual practice programs.

The game uses basic Python concepts along with built-in modules to create an interactive experience through the terminal.

The main goal of this project was not complexity, but to apply the concepts I had learned and understand how they work together in a complete program.

---

## 🧠 Concepts Used

The project helped me practice:

- 📝 Python Lists
- 🎲 `random` module
- ⏱️ `time` module
- 🔄 Loops and conditional statements
- 📦 Variables and basic data types
- ⌨️ User input
- 🖥️ Basic terminal interaction

---

## 🛠️ Technologies

- **Language:** Python
- **Libraries/Modules:** `random`, `time`
- **Environment:** Terminal / Command Line
